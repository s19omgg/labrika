# Local fonts

LABRICA uses Onest for interface text and JetBrains Mono for figures and compact labels. Variable fonts include Cyrillic and Latin; files are served locally, with no requests to third-party font services.

- Onest: [upstream project](https://github.com/simpals/onest), [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/onest). Unmodified `Onest[wght].ttf`, weights 100–900. License: `onest-OFL.txt`. SHA-256: `966c5c29b4755da84b6854d5c21dd4eaa2420225d0e9874de602de176d4a9f31`.
- JetBrains Mono: [upstream project](https://github.com/JetBrains/JetBrainsMono), [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/jetbrainsmono). Unmodified `JetBrainsMono[wght].ttf`, weights 100–800. License: `jetbrains-mono-OFL.txt`. SHA-256: `48715a42ec242c21e9f02692891e147d022299a52e48d5e413e1a942193ffeda`.
