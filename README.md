# LABRIKA

Отдельный репозиторий LABRIKA, выделенный из общего проекта с YGROUP.

## Локальный запуск

```bash
npm install
npm run dev
```

Приложение: `http://localhost:5173/`  
Админ-панель: `http://localhost:5173/admin`

## Сборка

```bash
npm run build
```

Готовая статическая сборка появится в `dist/`.

## Vercel

Репозиторий можно импортировать в Vercel как Vite-проект. Команда сборки: `npm run build`, output directory: `dist`.

Главный интерфейс доступен с корня `/`, админ-панель — `/admin`.

### Важно про серверные функции

Интерфейс LABRIKA собирается и открывается как обычный Vite-сайт. Локальные API генерации креативов и согласований лежат в `server/` и подключаются при локальном запуске через Vite middleware / `npm run server`. Для полноценного production-развёртывания этих API понадобится отдельный постоянный Node backend и постоянное хранилище; статический деплой Vercel сам по себе их не сохраняет между запросами.

## Секреты

`.env`, `.data`, ключи и сертификаты исключены через `.gitignore`. Реальные API-ключи в GitHub не добавляйте.
