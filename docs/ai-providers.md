# Подключение AI

LABRICA: `/labrika/admin/` → Настройки → Генерация контента. Конфигурация общая для аккаунтов LABRICA.

Для открытия конфигурации нужен ключ управления из локального `.data/approval-issuer.key` (или `APPROVAL_ISSUER_KEY`, если он задан серверу). Его вводят только в настройках администратора; не отправляют в чат, не размещают в клиентском коде и не публикуют. Ключи провайдеров хранятся на сервере в зашифрованном `.data/ai-providers.json`. Пустое поле ключа при сохранении оставляет прежний ключ. Проверка доступа не запускает платную генерацию; доступ к конкретной модели и баланс окончательно проверяются сервисом при запросе.

- OpenAI: API key, ID текстовой модели и модели изображения. Responses API используется для идей, текста, чата, планов, кампаний и переработки материала. По умолчанию `gpt-6-astra` и `gpt-image-2.5-flare`; их можно заменить в форме на модели, доступные вашему проекту. История и Brand Brain передаются как контекст, `store:false`.
- Higgsfield: Key ID + Key Secret. Модель `bytedance/seedance-2.0/image-to-video` либо `wan/v2.7/image-to-video`.
- Изображения: реальные ответы image-generation tool с пользовательскими референсами, без подстановки SVG-шаблонов.
- Видео: сценарий → согласованные ключевые кадры → реальные видеосцены → FFmpeg → единый MP4. Видео 15/30/45/60 секунд собирается из сцен по 5 секунд; выбранный формат и итоговая длительность проверяются. Звук и озвучка зависят от выбранной модели и сценария; отдельная музыкальная библиотека и отдельный TTS не подключены. При изменении сцены перегенерируются только её кадр/клип и итоговый монтаж.

`ffmpeg-static` устанавливает исполняемый файл монтажного инструмента. Можно указать `FFMPEG_PATH` вместо него. Генерация видео требует обоих провайдеров и работающего FFmpeg. Файлы для монтажа удаляются после завершения. Восстановление незавершённых AI-задач после перезапуска сервера ещё не реализовано.

Маршруты: `GET/PUT /api/ai/providers/:edition`, `POST /api/ai/providers/:edition/check`, `DELETE /api/ai/providers/:edition/:provider` требуют `X-Approval-Key`. Клиентские `POST /api/ai/generate`, `GET /api/ai/capabilities` и `/api/creative/*` используют `X-Product-Edition: labrika`. Названия сервисов, модели и ключи не показываются в пользовательском интерфейсе LABRICA.

Живые генерации при разработке не запускались. Контракты проверены подменой внешних ответов, монтаж — настоящим FFmpeg на тестовых клипах. После добавления ключей сначала проверьте доступ, затем выполните небольшую генерацию в интерфейсе.

Официальные источники, проверены 26 сентября 2026:
- [OpenAI Responses](https://developers.openai.com/api/reference/resources/responses/methods/create)
- [OpenAI image generation tool](https://developers.openai.com/api/docs/guides/tools-image-generation)
- [GPT-6 Astra](https://developers.openai.com/api/docs/models/gpt-6-astra)
- [Higgsfield Seedance 2.0 API](https://open.higgsfield.ai/models/bytedance/seedance-2.0/image-to-video/api-reference)
- [Официальный Higgsfield Python SDK](https://github.com/higgsfield-ai/higgsfield-client)

Это локальная интеграция: перед публичным доступом генерацию нужно связать с серверными сессиями, тарифными квотами и ограничением расхода по пользователю.
