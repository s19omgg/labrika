# Подключение генерации креативов

Интерфейс и серверная цепочка готовы к провайдеру. До его выбора API возвращает 503 при создании; пустой результат, шаблонная картинка или запись Canvas не выдаются за AI-генерацию. Проверки используют отдельные тестовые адаптеры.

## Запуск с адаптером

```sh
CREATIVE_GATEWAY_URL=https://your-private-adapter.example/api \
CREATIVE_GATEWAY_KEY=your-server-side-key \
npm run dev -- --port 3000
```

Переменные задаются окружению процесса; `.env.example` — перечень параметров, автоматического чтения `.env` нет. Не используйте префикс `VITE_`: секрет нужен только серверу. Адрес адаптера должен быть HTTPS (HTTP допустим для localhost). Переадресации запрещены. Таймаут каждого этапа — 10 минут; закрытие генератора отменяет задачу и передаёт AbortSignal адаптеру.

Адаптер — выбранная впоследствии интеграция с моделью/видеоредактором, а не произвольный URL API любой модели. Нужно реализовать пять POST-маршрутов ниже или передать объект с аналогичными методами в `createCreativeHandler({adapter})`. Авторизация исходящих запросов: `Authorization: Bearer CREATIVE_GATEWAY_KEY`.

| Маршрут | Ввод | Ответ |
|---|---|---|
| `/image` | `brief` напрямую: `prompt`, `references`, `topic`, `postText`, `brandContext` | `{image: "data:image/png;base64,..."}` |
| `/storyboard` | `brief` напрямую, включая `duration`, `aspect`, `mode` | `{title, caption, style?, music?, scenes: [{heading, description, duration, voiceover?, sound?, transition?, motion?, composition?, characters?, camera?}]}` |
| `/keyframe` | `{brief, style, scene, previous?, first?}`; previous/first — изображения предыдущей и первой сцен | `{image: "data:image/png;base64,..."}` |
| `/animate` | `{brief, style, scene, previous?}`; scene содержит ключевой кадр, previous — предыдущий клип | `{video: "data:video/mp4;base64,..."}` |
| `/compose` | `{brief, title, caption, music, style, scenes}` со всеми кадрами и клипами | `{video: "data:video/mp4;base64,...", duration: 30}` |

`references` — до 10 `{name, data}` в PNG/JPEG/WebP, по 5 МБ, суммарно около 15 МБ. `brandContext` содержит подтверждённые сведения и правила бренда. `description` — понятное человеку описание сцены; служебные поля камеры, движения, озвучки и композиции остаются на сервере. После изменения описания сцены её старые технические указания сбрасываются: адаптер должен сформировать их заново из новой версии.

Сценарий: 1–24 сцены по 0–15 секунд, сумма строго соответствует выбранным 15/30/45/60 секундам. Адаптер отвечает за реальную генерацию, визуальную последовательность персонажей и объектов, правильное разрешение/aspect ratio, монтаж, переходы, музыку, звук/озвучку по сценарию и конечное кодирование. Сервер проверяет заявленную длительность и тип data URL; декодирование и проверку реальной длительности/кодеков необходимо выполнить в адаптере. Поддерживаются PNG/JPEG/WebP и MP4/WebM. Передача результата — только data URL, без загрузки пользовательских URL сервером.

## API приложения

- `GET /api/creative/capabilities` — настроено ли подключение и доступные параметры.
- `POST /api/creative/jobs` — `{kind, prompt, references, topic?, postText?, brandContext?, duration?, aspect?, mode?}`; возвращает `id` и секретный `token` только при создании.
- `GET /api/creative/jobs/:id` — текущий этап, публичный сценарий, превью, готовый файл.
- `POST /api/creative/jobs/:id/continue` — `{scenes}` после проверки сценария.
- `POST /api/creative/jobs/:id/scene` — `{id, description}`; обновляет только выбранные кадр/клип и собирает видео из всех сцен.
- `DELETE /api/creative/jobs/:id` — отменяет работу и удаляет задачу.

Последние четыре маршрута требуют `X-Creative-Token`. Чужой/неверный токен возвращает 404. Состояния: `running`, `review`, `complete`, `error`; этапы: `script`, `visuals`, `animation`, `montage`, `ready`. В режиме проверки цепочка останавливается перед созданием кадров, пока пользователь не подтвердит сценарий.

## Локальные ограничения

Задачи живут в памяти процесса до часа неактивности и теряются при перезапуске. Одновременно сохраняется до 40 задач. Крупные результаты в виде data URL могут исчерпать память процесса/хранилище браузера; перед публичным запуском нужны очередь, объектное хранилище, серверные сессии и организации, тарифные лимиты и проверка доступа к созданию задач. Токен защищает чтение конкретной задачи, но не заменяет аутентификацию публичного сервиса.
