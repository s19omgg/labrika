# Social icons

The application uses monochrome SVG geometry from these official resources, fitted proportionally inside the existing circular platform badges:

- MAX: https://go.max.ru/brandbook — `max-white.zip`, the silhouette from `Max white.svg`.
- Threads: https://www.meta.com/brand/resources/threads/ — `Threads-Brand-Resource-Center.zip`, the current white logo.
- Дзен: https://dzen.ru/about/download — `dzen-dark/dark-stella.svg`.
- TikTok: https://developers.tiktok.com/docs/en/getting-started-design-guidelines — `logo-pack.zip`, the standalone monochrome note from `Button_No outline.svg`.
- VK: https://vk.com/brand — the monochrome VK symbol.

Assets identify their respective services; their trademarks belong to those services. The original geometry is retained without colored backplates or wordmarks.
